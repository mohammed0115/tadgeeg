# أسبقية بيانات الاستخراج — قياس الشحنة

## القاعدة

> قيمة صالحة من محلل لا تُستبدل بقيمة من احتياطي فاشل؛ الاحتياطي يملأ الفراغ ولا يمحو المملوء.

## التغيير

تضيف الشحنة دمجاً نقياً في `apps/invoices/services/processor.py`. يستقبل أولاً بيانات المحلل المنظمة ثم البيانات المطَبَّعة، ويستخدم ناتج AI أو regex fallback لإكمال الحقول الغائبة فقط. الصفر و`False` قيمتان صريحتان لا فراغان؛ لا يجوز للحل الاحتياطي أن يستبدلهما.

## الحراسة

شغّل الاختبار المحدد:

```text
pytest -q tests/test_extraction_fallback_precedence.py tests/test_structured_invoice_rows.py --no-cov
4 passed
```

| الحارس | ما يثبت |
|---|---|
| نمط الأسبقية | قيمة المحلل لا تستبدل بشظية `oice` أو صفر؛ وتظل الحقول الغائبة قابلة للملء |
| JSON حقيقي | يمرر محلل JSON الرقم والمورد و1000/150/1150 عبر merge حتى عند fallback فاشل |
| XLSX حقيقي | صف XLSX منظّم لا تفقد قيمه أمام fallback |

لا تستعمل الحراسة `MagicMock`.

## قياس ما بعد الشحنة

استُخدمت عينات متطابقة القيم في JSON وPDF وXLSX وPNG. النتيجة المتعلقة بهذه الشحنة محددة:

| الصيغة | النتيجة بعد أسبقية الدمج | الحكم |
|---|---|---|
| JSON | الرقم `XFMT-2026-001` والمورد و1000/150/1150 بقيت كما أخرجها المحلل، مع إضافة VAT المورد الغائبة فقط من fallback | **تم إصلاح العيب المشترك** |
| PDF | subtotal وVAT والإجمالي قرئت، لكن fallback ما زال يكتب رقم الفاتورة `Invoice` بدل الرقم الفعلي | عيب regex مستقل |
| XLSX key/value | الرقم `oice` والمورد المجتزأ وVAT صفر بقيت؛ المحلل ليس نموذج key/value فاتورة | عيب محول XLSX مستقل |
| PNG | الإدخال فشل لأن Tesseract غير موجود في بيئة القياس | حاجز جاهزية تشغيل؛ Dockerfile يعلن الحزمة لكن لا توجد بوابة تثبتها |

فشل OpenAI الحالي (`'NoneType' object is not subscriptable`) مسجل كسبب للانتقال إلى fallback، لكنه خارج نطاق هذه الشحنة. لا تعالج هذه الشحنة قبول JSON المفرد أو محول XLSX أو regex أو Tesseract.

## بوابة الشحنة

أعيد تشغيل البوابة الكاملة بعد التغيير وكانت النتيجة:

```text
1 failed, 4035 passed, 4 skipped, 18 subtests passed in 308.87s
```

الفشل الوحيد هو فحص `mtime` المعروف لكتالوج العربية (`django.po` أحدث بـ0.004 ثانية من `django.mo`)؛ لا يقع في مسار الاستخراج ولا تنتج عنه علامة اختبار لشيفرة الشحنة.
