# ورقة XLSX الثنائية لفاتورة واحدة

## المشكلة

كان محول XLSX يعامل ورقة ذات رأس `Field | Value` كسجلات عديدة: صف للرقم وصف للمورد وصف للمبلغ. لا تمثل هذه الصفوف فواتير مستقلة، ولذلك يصل مسار الرفع إلى fallback بشظايا مثل `oice` أو مبالغ غير مكتملة.

## التغيير

حين يكون رأسا ورقة XLSX هما `Field` و`Value` (بلا حساسية لحالة الأحرف)، يجمع المحول كل الصفوف إلى حمولة منظمة واحدة برقم صف `2`. تظل الأوراق ذات الرؤوس الأخرى جداول معاملات صفية كما كانت.

## الحراسة

شُغل:

```text
pytest -q tests/test_structured_invoice_rows.py --no-cov
3 passed
```

ينشئ الحارس ملف XLSX فعلياً بـopenpyxl ويثبت أن الرقم والمورد و1000/150/1150 تصير فاتورة واحدة منظمة. لا يستخدم Mock.

## خارج النطاق

لا يعالج هذا التغيير fallback PDF أو OCR للصورة أو خدمة OpenAI أو جداول XLSX ذات مخطط مختلف. تلك مسائل مستقلة تقاس وتصلح في شحنات لاحقة.
