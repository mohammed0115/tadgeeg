# الجزء الثاني — قرار التصميم

## ٢.١ 🔴 **MySQL نفسها — بجدولين. لا قاعدة منفصلة.**

**والقرار مبنيّ على حجمك لا على المبدأ.**

| لماذا لا تُفصَل الآن | |
|---|---|
| **لا `DATABASE_ROUTERS`** | الفصل يعني بناء router · وكل نموذج جديد يصير قرار توجيه |
| **المعاملات تنكسر** | `transaction.atomic` **لا يمتدّ عبر قاعدتين** ⇒ تُلتزَم الحمولة وتتراجع الفاتورة |
| **الهجرات والنسخ تتضاعف** | و`update.sh` يُهاجِر قاعدة واحدة |
| **والحجم لا يستدعيه** | مئات يوميًّا ليست ملايين |

## ٢.٢ والفصل يكون بجدولين

```
AIUsageRecord    →  وصفية · دائمة · صغيرة    ← الفوترة تقرأها
AIUsagePayload   →  حمولة · مؤقّتة · كبيرة   ← التشخيص وقت الحاجة
```

**فاستعلام الفوترة لا يجرّ كيلوبايتات لا يحتاجها.**

## ٢.٣ ومتى تُفصَل فعلًا — عتبات مكتوبة

قِس **بعد أسبوع من التشغيل**:

| المؤشّر | العتبة |
|---|---|
| حجم الجدولين من القاعدة | **> 20%** |
| زمن استعلامات التدقيق | ارتفاع محسوس |
| صفوف/يوم | **> 100,000** |

⇒ **وحينها الوجهة ليست MySQL ثانية** — بل مخزن سلاسل زمنية أو ملفات
مضغوطة. **ولا يُصمَّم له قبل أن تُثبت الحاجة.**

# الجزء الثالث — النموذجان

## ٣.١ `AIUsageRecord` — دائم

```
organization        FK · 🔴 **إلزامي لا اختياري**
created_at          · db_index
model               gpt-4o · gpt-4o-mini · …
operation           extraction · classification · narrative · assistant

estimated_cost      🔴 بسعر النموذج **وقت النداء**
status              success · failed
failure_kind        auth_401 · rate_limit · timeout · payload · other
latency_ms
document_id         اختياريّ — للربط بالفاتورة

Meta: index (organization, created_at)
```

## ٣.٢ `AIUsagePayload` — مؤقّت

```
usage_record        OneToOne · CASCADE
request_payload · response_payload
```

⚠️ **ولا ترويسة `Authorization` ولا مفتاح** — ولو مُقنَّعًا.

## ٣.٣ ثلاثة قيود إلزامية

**🔴 `organization` إلزامي.** ودرسنا المقيس: `DocumentCanonicalData` وُضع
بلا مالك فتراكم **1,003 صفًّا بلا نطاق**. **والوسيط الإلزامي يمنع
المستدعي القادم من نسيانه — ويرفع استثناءً لا يمرّ صامتًا.**

**🔴 والكلفة بسعر وقت النداء.** الأسعار تتغيّر، **وسجلّ فوترة يُعاد
حسابه بسعر جديد يُنتج رقمًا لا يطابق ما دُفع.**

**🔴 والتقليم يُبنى مع الجدول لا بعده.** أمر إداري يحذف الحمولات بعد
٣٠ يومًا **والوصفية تبقى** — وإلا اكتُشف الحجم حين يصير مشكلة.
