# شعارات الشركاء المبذورة

ضع شعار الشريك هنا باسم الـslug الخاص به:

    bironex-holding.png

الامتدادات المقبولة بالترتيب: `.png` `.jpg` `.jpeg` `.webp` `.svg`

`manage.py seed_partners` يلتقطه ويرفعه **مرة واحدة فقط** — إن كان للشريك شعار
مرفوع بالفعل فلن يُستبدل، حتى لا يدهس رفعًا يدويًا من لوحة الإدارة.

**لماذا هنا لا عبر لوحة الإدارة؟** الرفع اليدوي يجب تكراره على `dev` و`test`
و`live`، ويضيع عند إعادة إنشاء أي media volume — وهو ما وقع فعلًا. الملف في
المستودع يُنشر مع كل بيئة تلقائيًا.

الشعار **عام بطبيعته** (مقصود للعرض)، فمساره `media/partners/logos/` لا
`private_media/` الذي يخصّ السجلات التجارية والشهادات.
