### 1.1 المنظومات الثلاث كما قيست

**(١) `core/services/invoice_validator.py`** — درجة جودة/امتثال · **المرتفع جيّد**

🔴 **الأوزان المعلنة في README (حرجة 25 · عالية 15 · متوسطة 8 · منخفضة 3) لا تُستخدم في حساب الدرجة إطلاقًا.** كل قاعدة تزن مثل الأخرى. الخطورة تُرفق بنتيجة القاعدة للعرض فقط.

**(٢) `apps/invoices/services/validation_service.py::merge_risk_assessment`** — **هذه هي التي تكتب `invoice.risk_level` فعلًا**
```

```
🔴 **لا يوجد `critical` هنا إطلاقًا.** فالفاتورة لا تستطيع أن تكون «حرجة» عبر المسار الحيّ، مهما فشلت من قواعد. و`_score_to_risk` في (١) يحسب `critical` ثم يُهمَل.

**(٣) `apps/rule_engine/risk/risk_engine.py`** — يكتب `AuditRun.risk_score` / `AuditRun.risk_level`
