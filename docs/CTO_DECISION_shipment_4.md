## ١. 🔴 العيب: `run_audit_compat` معطّل في الإنتاج — تحققت منه

المنفّذ أبلغ عن `RecursionError`. **مؤكَّد، وأخطر مما وصفه.**

### السلسلة

```python
# apps/billing/quota_gate.py:255-266
original = compat_mod.run_audit_compat        # الأصل الحقيقي، مُلتقَط صحيحًا
def _gated(*args, **kwargs):
    return run_audit_with_quota(*args, **kwargs)
_gated._original = original                   # ← مخزَّن ولا أحد يقرأه
compat_mod.run_audit_compat = _gated          # ← الوحدة استُبدلت

# apps/billing/quota_gate.py:137-139 — داخل run_audit_with_quota
from apps.rule_engine.pipeline.v2.compat import run_audit_compat as _original
#                                              ↑ وقت النداء = _gated نفسه
audit_run = _original(...)                    # ← ارتداد لا نهائي
```

**الأصل محفوظ في `_gated._original` (السطر 264) ولا يُقرأ أبدًا.** الاستيراد
داخل الدالة يقع بعد الترقيع، فيُعيد النسخة المُرقَّعة.

### وهو مُفعَّل افتراضيًا

```python
# apps/billing/apps.py::ready()
install_gate()                                # كل إقلاع

# settings_canonical.py:257
BILLING_QUOTA_GATE_ENABLED = os.environ.get(..., "true").lower() != "false"
```

بلا متغيّر بيئة ⇒ **الحارس مُثبَّت في كل عملية Django في الإنتاج.**

### الأثر — أوسع من الخطوة ٤

**فالفواتير تعمل، والمستندات المُوقَّعة الأحد عشر لا تُدقَّق عبر V2 اليوم.**

### وأثره على الخطوة ٤ — حاسم

الخطوة ٤ توجّه `core/services/pipeline.py` إلى الجسر، والجسر ينادي
`run_audit_compat`. **أي أنها كانت ستُبدّل مسارًا سليمًا (`AuditEngine`) بمسار
معطّل — وتُسقط تدقيق المستندات بالكامل.**

> **الخطوة ٤ مُجمَّدة حتى يُصلَح هذا. وهي أول مرة يمنع فيها عيبٌ خطوةً في
> الخطة، لا بوابةٌ صمّمتُها.**

### ولماذا لم يلتقطه أحد

**3,936 اختبارًا تمرّ، ولا واحد منها يلمس هذا المسار.** الحارس يُثبَّت في

`test_qa_fixes.py` و`test_post_qa_hardening.py`) — أي **تتخطّى الترقيع الذي
يُنشئ العيب**.

هذا صنف جديد لسجل الانحرافات: **عيب يعيش في الفجوة بين ما تستدعيه الاختبارات
وما يستدعيه الإنتاج.**

## ٢. تصحيح استدلالي: «V2 ≥ V1 دائمًا» لم يصمد

كتبت في قرار الشحنة ٣ أن المُعدِّلات أحادية الاتجاه ⇒ V2 ≥ V1 دائمًا.

**القياس: 222 من 400 بفارق سالب** (−0.5 في 219 · −1.5 في 3).

وتشخيص المنفّذ دقيق: **الاستدلال صحيح عن المُعدِّلات، وخاطئ عن النتيجة.**
المُعدِّلات تُضيف فوق **أساس V2**، لا فوق درجة V1 — وأساسا الأنبوبين مختلفان.

فالصياغة الصحيحة:

> **الجزء المُعدِّل من V2 أحادي الاتجاه. أما الفارق الكلي بين الأنبوبين فليس
> كذلك، لأن الأساسين مختلفان.**

الفارق صغير (≤ 1.5 نقطة) ولا يقلب مستوى، لكن **الادّعاء كان مطلقًا والواقع
ليس كذلك**. سُجّل.

## ٣. القياس: صفر انقلاب — مقبول بتحفّظ صريح

| المقياس | النتيجة |
|---|---|
| العيّنة | 400 مستند · `order_by("id")` · صفر أخطاء |
| فارق > 0 | **0 / 400** |
| **انقلاب `blocks_approval` → True** | **0** |
| انقلاب → False | 0 |
| أقصى فارق | **0.0** (الحدّ النظري 80) |
| القراءة-فقط | ✅ `AuditRun` = 3 قبل وبعد |

**إثبات القراءة-فقط بعدّاد لا بادّعاء** — هذا هو المعيار.

### ⚠️ لكن النتيجة قد تكون فارغة المعنى

المنفّذ رفعها بنفسه: **صفر انقلاب قد يعني «آمن» أو «الكوربوس لا يمثّل الإنتاج».**

الدليل في البيانات نفسها: أقصى فارق **0.0**، أي **لم ينطلق أي مُعدِّل ولا مرة
واحدة**. والمُعدِّلات ترجع بلا تغيير إن كان سياقها فارغًا:

```python
vendor = context.vendor_context
if not vendor: return risk_data
```

وتركيب العيّنة يؤكّده: 211 `fixed_asset` و167 `purchase_order` — **صفر
`sales_invoice`**، وهو النوع الوحيد الذي يحمل سياق مورد في الإنتاج.

> **الحكم: القياس صحيح، والعيّنة غير ممثِّلة.** فهو يُثبت أن الأنبوبين
> متكافئان **حين لا ينطلق مُعدِّل**، ولا يُثبت شيئًا عن حين ينطلق.
>
> والحدّ النظري +80 يبقى قائمًا وغير مُختبَر.

**البوابة تبقى مفتوحة — لكن سببها تغيّر.** لم تعد «لا نعرف»، بل «الكوربوس لا
يحوي الحالة الخطرة».
