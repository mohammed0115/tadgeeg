==================================================
QuotaService
==================================================

أنشئ:

apps/billing/services/quota_service.py

وفيه class QuotaService:

1. get_active_subscription(organization)

يرجع الاشتراك الفعال:
- status active أو trialing
- starts_at <= now
- ends_at >= now

2. get_remaining_quota(organization)

remaining = invoice_limit - used_invoices - reserved_invoices

3. can_audit(organization, quantity=1)

يرجع:

{
  "allowed": true/false,
  "reason": "...",
  "remaining": number,
  "subscription": subscription
}

4. reserve_invoice_audit(organization, document=None, quantity=1)

- استخدم transaction.atomic
- استخدم select_for_update على الاشتراك
- تحقق أن remaining >= quantity
- زِد reserved_invoices
- أنشئ UsageLedger action=reserve
- إذا لا يوجد رصيد ارفع QuotaExceeded

5. consume_invoice_audit(organization, document=None, audit_run=None, quantity=1)

- استخدم transaction.atomic
- قلل reserved_invoices
- زِد used_invoices
- أنشئ UsageLedger action=consume

6. release_invoice_audit(organization, document=None, quantity=1, reason="")

- استخدم transaction.atomic
- قلل reserved_invoices
- لا تزِد used_invoices
- أنشئ UsageLedger action=release

القاعدة الأساسية
==================================================

لا تخصم من الرصيد عند رفع الملف فقط.
الخصم يكون عندما يتم تشغيل التدقيق فعليًا وينتج تقرير/نتيجة تدقيق.

استخدم 3 مراحل:

1. reserve
عند بدء التدقيق.

2. consume
عند اكتمال التدقيق بنجاح.

3. release
إذا فشل التدقيق بسبب خطأ من النظام أو لم ينتج تقرير.

- audit celery tasks

قبل تشغيل أي audit:

1. استخرج organization.
2. استدع:
QuotaService.can_audit(organization)

3. إذا allowed=false:
- لا تبدأ audit.
- اجعل audit_status = quota_exceeded أو billing_required.
- أرجع رسالة:
  "لقد استهلكت جميع الفواتير المتاحة في باقتك. يرجى ترقية الاشتراك."

4. إذا allowed=true:
- استدع:
QuotaService.reserve_invoice_audit(organization, document)
- ثم شغّل Audit Pipeline.

بعد اكتمال Audit Pipeline:

إذا success:
- استدع:
QuotaService.consume_invoice_audit(organization, document, audit_run)

إذا failed بسبب خطأ من النظام:
- استدع:
QuotaService.release_invoice_audit(organization, document, reason)
