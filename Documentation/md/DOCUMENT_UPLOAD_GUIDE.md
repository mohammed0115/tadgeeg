# دليل رفع المستندات المالية — منصة تدقيق (Tadgeeg)

> شامل لجميع أنواع الملفات: **Excel · CSV · JSON · PDF · صور**

---

## كيف يعمل النظام

```
┌──────────────────────────────────────────────────────┐
│                   الملف المرفوع                      │
├──────────┬───────────┬────────────┬──────────────────┤
│  Excel   │   CSV     │   JSON     │   PDF / صورة     │
│ .xlsx    │  .csv     │  .json     │  .pdf / .jpg     │
│ .xls     │           │  .jsonl    │  .png / .tiff    │
└────┬─────┴─────┬─────┴─────┬──────┴──────────┬───────┘
     │           │           │                 │
     ▼           ▼           ▼                 ▼
  pandas      pandas      pandas           Tesseract OCR
  مباشر       مباشر       مباشر           ← استخراج نص
     │           │           │                 │
     └───────────┴───────────┴────────┬────────┘
                                      ▼
                              OpenAI GPT-4o
                          ← استخراج + تدقيق ذكي
                                      │
                                      ▼
                           حقول موحدة → قاعدة البيانات
```

**Excel / CSV / JSON**: يقرأها النظام مباشرة بدقة عالية + يدعمها الذكاء الاصطناعي
**PDF / صور**: يستخرج النظام النص بـ OCR ثم يحلله الذكاء الاصطناعي

# 1. أمر الشراء (Purchase Order)

## الحقول المستخرجة

| الحقل | المعنى | مصدر PDF/صورة | مصدر Excel/CSV/JSON |
|-------|--------|----------------|----------------------|
| `po_number` | رقم أمر الشراء | AI | عمود: `رقم أمر الشراء` / `po_number` |
| `po_date` | تاريخ الإصدار | AI | عمود: `تاريخ الإصدار` / `po_date` |
| `delivery_date` | تاريخ التسليم | AI | — |
| `vendor_name` | اسم المورد | AI | عمود: `اسم المورد` / `vendor_name` |
| `vendor_vat_number` | الرقم الضريبي للمورد | AI | — |
| `vendor_cr_number` | السجل التجاري للمورد | AI | — |
| `department` | القسم | AI | — |
| `currency` | العملة | AI | عمود: `العملة` / `currency` |
| `subtotal` | إجمالي قبل الضريبة | AI | محسوب تلقائياً |
| `vat_amount` | ضريبة القيمة المضافة | AI | عمود: `ضريبة القيمة (15%)` / `vat_amount` |
| `total_amount` | الإجمالي الكلي | AI | عمود: `الإجمالي الكلي (SAR)` / `total_amount` |
| `line_items` | بنود الأمر | AI | صفوف الجدول |

## Excel / CSV — أعمدة الجدول

```
| الوصف | الكمية | سعر الوحدة (SAR) | إجمالي قبل الضريبة | ضريبة القيمة (15%) | الإجمالي الكلي (SAR) |
```

| اسم العمود | الاسم البديل (EN) | ضروري؟ |
|------------|-------------------|--------|
| `الوصف` | `description` / `item` | ✅ |
| `الكمية` | `qty` / `quantity` | ✅ |
| `سعر الوحدة (SAR)` | `unit_price` / `price` | ✅ |
| `إجمالي قبل الضريبة` | `subtotal` / `amount` | اختياري |
| `ضريبة القيمة (15%)` | `vat_amount` / `vat` | اختياري |
| `الإجمالي الكلي (SAR)` | `total` / `total_amount` | اختياري |

## JSON — هيكل الملف

```json
{
  "po_number": "PO-2025-001",
  "po_date": "2025-01-15",
  "vendor_name": "شركة الأفق للتوريدات",

```
| الوصف | الكمية | سعر الوحدة (SAR) | إجمالي قبل الضريبة (SAR) | نسبة الضريبة (%) | ضريبة القيمة (SAR) | الإجمالي الكلي |

| اسم العمود | الاسم البديل (EN) | ضروري؟ |
|------------|-------------------|--------|
| `الوصف` | `description` / `item` | ✅ |
| `الكمية` | `qty` / `quantity` | ✅ |

## قواعد عامة لجميع الملفات

### صيغ التاريخ المقبولة
| الصيغة | مثال |
|--------|------|
| `YYYY-MM-DD` ✅ (مفضل) | `2025-03-15` |
| `DD/MM/YYYY` ✅ | `15/03/2025` |
| `DD-MM-YYYY` ✅ | `15-03-2025` |

### قواعد الأرقام
- أدخل الأرقام **بدون فواصل آلاف** (`1500` وليس `1,500`)
- أدخل الأرقام **بدون رمز العملة** (`1500` وليس `1500 SAR`)
- استخدم **النقطة** فاصلاً عشرياً (`1500.50` وليس `1500،50`)
- أرقام العملة الافتراضية: **SAR**

### أسماء الأعمدة — المرونة
النظام يقبل أي من هذه الصيغ لنفس العمود:
```
سعر الوحدة (SAR)   ✅   →   سعر_الوحدة   ✅   →   unit_price   ✅   →   Unit Price   ✅
```

### أسباب شائعة للقراءة الخاطئة

| المشكلة | السبب | الحل |
|---------|-------|------|
| سعر الوحدة = صفر | اسم عمود غير مطابق | استخدم أحد الأسماء المدرجة في الجدول |
| التاريخ لا يُقرأ | صيغة غير مدعومة | استخدم `YYYY-MM-DD` |
| الإجمالي خاطئ | خلايا الأرقام بصيغة نص | في Excel: تأكد أن نوع الخلية **رقم** وليس **نص** |
| لا توجد بيانات | الصف الأول بيانات وليس رأس جدول | أضف صف رأس الجدول (أسماء الأعمدة) في أول صف |
| OCR غير دقيق (PDF/صورة) | صورة منخفضة الدقة أو مائلة | استخدم دقة 300dpi على الأقل، الصورة مستقيمة |
| AI لا يستخرج بيانات | النص في الصورة غير واضح | فضل رفع ملفات هيكلية (Excel/CSV/JSON) للبيانات الجداولية |
