## ٢. الفرع الميت — أُصلح إظهاره

```
ERROR [OpenAI] Authentication failed: Error code: 401 —
  'Incorrect API key provided: sk-proj-****7uQA', code: 'invalid_api_key'
```

`classify_document` يبتلع ذلك ويُعيد `{"document_type":"other",
"confidence":0.0,"reason":""}` — وهو **شكل الإجابة نفسه**. فـ`_classify_ai`
كان يمرّره كأنه رأي نموذج نظر ولم يجد. خمسة من خمسة، **بثانية مفوترة لكل
مستند**.

الآن يُميَّز: `ai_unavailable: True` مع `ai_error`، وسجلّ بمستوى `error`
يقول صراحةً «لم يُصنَّف بالذكاء الاصطناعي، وهذا ليس أن الذكاء لم يجد شيئًا».

**ولا يرفع استثناءً** — فشل تصنيف لا يجوز أن يُسقط رفعًا.

وهذا هو تمييز `NOT_APPLICABLE` عن `INSUFFICIENT_DATA` الذي تحرسه
`apps/audit_platform/status.py`: **«لا نعرف» ليست «لم نستطع النظر».**

## 🔴 ٣. الصيغة — أربعة مرشّحين، والاختيار قرار CTO

```python
document_classifier.py:198
confidence = round(min(best_score / max(total, 1), 1.0), 3)
```

**حصّة، لا تمييز.** والمقيس على الكوربوس أعلاه:

| الحالة | الدرجات | A حصّة | B هامش | C رأس-برأس | **D مركّب** | يجب |
|---|---|---|---|---|---|---|
| فاتورة `SuperStore` حقيقية | `invoice:6 · bank_statement:3` | 0.667 ❌ | 0.500 ❌ | 0.667 ❌ | **0.833 ✅** | يعبر |
| كشف رواتب عربي | `payroll:3` | 1.0 ✅ | 1.0 ✅ | 1.0 ✅ | **0.750 ✅** | يعبر |
| سند قبض (ضربة واحدة) | `receipt:2` | 1.0 ❌ | 1.0 ❌ | 1.0 ❌ | **0.667 ✅** | يسقط |
| كشف عميل ⇐ قُرئ `bank_statement` | `bank_statement:2` | 1.0 ❌ | 1.0 ❌ | 1.0 ❌ | **0.667 ✅** | يسقط |
| | **الصواب** | **1/4** | **1/4** | **1/4** | **4/4** | |

```
A = best / total                       ← الحالية
B = (best − second) / best             ← هامش
C = best / (best + second)             ← رأس برأس
D = 0.5·min(1, best/6) + 0.5·(best/(best+second))
    ↑ قوة مطلقة (كم دليلًا وُجد)      ↑ تمييز (كم يفوق الثاني)
```

**العيب الجوهري في A و B و C جميعًا أنها نسبية**: ضربة كلمة واحدة بلا
منافس تُعطي 1.0 في الثلاث. والمطلوب مكوّن **مطلق** يقول «كم دليلًا وجدنا
أصلًا» — وهو ما يضيفه D.

⚠️ **لم أشحن D.** الصيغة تحكم أي قواعد تُطبَّق على أي مستند، والاختيار
قرار معماري. والثابت `6` في D معايرة تحتاج كوربوسًا أوسع من 28 ملفًّا.

⚠️ **ولم أمسّ العتبة 0.70.** الصيغة أولًا، ثم تُعاير العتبة عليها.
