# النسخ الاحتياطي والاستعادة — تشغيل S3/MinIO

## الحالة

منصة التخزين في Tadgeeg تدعم مزود S3 أو MinIO من خلال `StorageProvider` و`StorageConfig` و`OrganizationStoragePolicy.backup_storage`. لا توجد وجهة حيّة مهيأة في هذه الشحنة؛ لذلك لا يُعد النسخ الحي أو الاستعادة الحية مكتملين قبل ضبط البيئة واختبار الاستعادة على خادم منفصل.

## متغيرات البيئة

توضع القيم في `deployment/docker/env/live.env` على الخادم فقط، ولا تُضاف إلى Git أو إلى هذه الوثيقة:

```dotenv
# يعيد استخدام مزود S3 للوسائط؛ يجب أن يكون bucket خاصاً ومشفراً.
AWS_STORAGE_BUCKET_NAME=
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_S3_REGION_NAME=me-south-1
AWS_S3_CUSTOM_DOMAIN=

# اختيارية عند استخدام MinIO أو S3-compatible endpoint.
BACKUP_S3_ENDPOINT_URL=
BACKUP_S3_BUCKET=
BACKUP_S3_PREFIX=tadgeeg-backups
```

يجب أن تكون الصلاحيات الأدنى للمفتاح: `PutObject` و`GetObject` و`ListBucket` داخل prefix النسخ فقط. لا تمنح حذفاً واسعاً أو صلاحيات على bucket الوسائط الأساسي.

## الإعداد في Tadgeeg

1. أنشئ مزود تخزين من نوع **S3** أو **MinIO** في واجهة إدارة التخزين.
2. أضف `StorageConfig` عالمياً للمزود، مع bucket وregion وendpoint عند MinIO. تحفظ أسرار المزود مشفرة في إعداد التخزين ولا تدخل في رقم WhatsApp أو إعدادات CRM.
3. عيّن المزود على أنه `backup_storage` في سياسة التخزين لكل منظمة أو في السياسة الافتراضية المناسبة.
4. استخدم زر اختبار اتصال المزود قبل تفعيل أي مهمة مجدولة.

## الجدولة والتدرج

تعمل سياسة الباقات كمصدر التردد المجمد عند الاشتراك:

| الباقة | التردد المجدول |
|---|---|
| مجانية | لا نسخ احتياطي |
| أساسية / متوسطة | أسبوعي |
| أعمال / احترافية | يومي |
| مؤسسات | ساعي |

تحتاج عملية النسخ الحي إلى worker وbeat يعملان مع البيئة نفسها. لا تُعد المهمة ناجحة لمجرد تشغيلها؛ يجب أن تحفظ manifest ومجموع SHA-256 ووقت الاستعادة.

## اختبار الاستعادة الإلزامي

لا تستعد إلى قاعدة الإنتاج. أنشئ قاعدة اختبار منفصلة، ثم نفذ بالترتيب:

1. استخرج نسخة واحدة من prefix المنظمة إلى مساحة مؤقتة مقيدة الصلاحية.
2. تحقق من checksum لكل ملف قبل التحميل.
3. شغّل الاستعادة في قاعدة/وسائط اختبار فقط.
4. نفذ `python manage.py check` واختبار عينة فاتورة ودليل تدقيق وسلسلة hash.
5. سجل زمن الاستعادة ونتيجتها، ثم احذف مساحة الاختبار المؤقتة وفق سياسة الأمان.

> لا تعتبر باقة النسخ الاحتياطي مكتملة تشغيلياً قبل نجاح هذا الاختبار في بيئة غير إنتاجية ثم توثيقه.
