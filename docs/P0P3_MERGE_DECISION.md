# قرار دمج `fix/p0-p3-hardening` في `claude`

> **التاريخ:** 2026-08-14
> **النطاق:** `claude` فقط؛ **لا** دمج إلى `main`، ولا نشر إنتاجي.
> **قرار CTO:** الدمج مسموح بعد مراجعة محلية، مع بقاء النشر محجوباً بالشروط أدناه.

## 1. القرار

يُدمج فرع `fix/p0-p3-hardening` في `claude` فقط. لا يغيّر هذا القرار مرجع الإنتاج؛ يبقى `main @ 3d29066` كما هو.

| البند | النتيجة الموثقة |
|---|---|
| بوابة الاختبارات | 4,041 ناجحاً، 4 متجاوزة، و18 اختباراً فرعياً ناجحاً؛ فشل واحد في حداثة كتالوج العربية مبني على `mtime` فقط |
| تحقق كتالوج العربية | `msgfmt --statistics django.po -o /tmp/check.mo` ثم `cmp` أثبتا تطابق المحتوى byte-for-byte؛ فشل `mtime` بيئي لا اختلاف في المحتوى |
| الهجرة `0017` والملء الرجعي | اختبارات تغطي ربط المطابقة الوحيدة، وترك المطابقات الغامضة أو غير المثبتة `NULL`، وإعادة التدقيق بعد الملء |
| تثبيت V1 | حارس يثبت `engine_version=2.0` تحت إعداد افتراضي `v2` في مسار الرفع الرسمي |
| فرق حمولة CSV | مُفسّر: الاستخراج السابق دقّق شظايا JSON؛ تصحيح `subtotal` واستبعاد التكرار الذاتي جعلا المدخل مطابقاً للفاتورة الفعلية |

## 2. سلوك الدمج

حدث تعارضان محلياً قبل وصول تصريح CTO المكتوب، ثم أُقرا بأثر رجعي. احتُفظ في `apps/rule_engine/api/views.py` بالمرور عبر `run_audit_compat` مع `engine_override="v1"`، وأزيل `apps/rule_engine/tasks/audit_tasks.py` من سقف مستوردي V1 المباشرين لأنه لم يعد يستورد الأنبوب مباشرة. بقي استثناءا GAAP وbootstrap بمبرراتهما المكتوبة.

> **انحراف حوكمة مسجل:** حُلّ تعارضان محلياً قبل وصول تصريح CTO. الحلان صحيحان وأُقرا بأثر رجعي، لكن لا يجوز أن يسبق حل التعارض التصريح مستقبلاً.

## 3. النشر محجوب

الدمج لا يجيز النشر. يبقى النشر محجوباً حتى تُغلق البنود التالية بقياسات مستقلة:

| # | الحاجب | سبب الحجب |
|---|---|---|
| 1 | الأدلة على فاتورة واحدة | الفرع يمس الاستخراج والتصنيف والتوجيه؛ لا تكفي عينة واحدة لإثبات النشر |
| 2 | المرجع الذهبي لا يحرس مسار الرفع | المولد يتجاوز `run_audit_compat` و`quota_gate` ومسار CSV |
| 3 | فحص المتصفح وبيان Whitenoise ويومان مراقبة | لا بد من تحقق واجهة وتشغيل مراقب قبل النشر |
| 4 | ثابت صيغة الثقة `6` بلا معايرة | أثره خارج العينة المحدودة غير مقاس |
| 5 | `blocks_approval` له مسارا قراءة | لا توجد خدمة مصدر حقيقة واحدة بعد |
| 6 | إشعار المدققين | أرقام اللوحات قد تتغير بعد التصحيح ويجب إبلاغ المستهلكين |

**بند إداري:** بيئة الاختبار نفسها تحجب اختبار الحمل وملف القفل وفحص الواجهة والمرجع الذهبي الموسع وأي مقارنة صحيحة بين فرعين. الإعدادات الحالية لا تسمح بقاعدة SQLite مشتركة عبر البيئة: `settings.test` يفرض `:memory:`، و`settings_canonical` يفسر `DB_NAME` غير الفارغ كإعداد MySQL حتى عند طلب SQLite.

## 4. بنود لا تُغلق بهذا الدمج

لا يعالج الدمج حذف `AuditEngine` ولا إعادة معايرة الثقة ولا إصلاح اختبار `mtime` ولا بيئة القياس الموسعة. هذه شحنات مستقلة؛ خلطها مع دمج مسار الرفع يخفي أثر كل تغيير.

## 5. قرار المتابعة

يبدأ العمل التالي فقط بعد ثبات `claude`: حذف `AuditEngine` لتقليل منظومات الحكم، ثم وثيقة معمارية توثق الدَّين المتبقي وقياسات النشر اللازمة.
